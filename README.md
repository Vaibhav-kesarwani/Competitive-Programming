# 🚀 Competitive Programming Solutions

A comprehensive collection of algorithmic problem solutions and contest implementations solved across various competitive programming platforms including **Codeforces**, **LeetCode**, **AtCoder**, **CodeChef**, and more. Written primarily in **C++**.

---

## 📂 Repository Structure

```text
Competitive-Programming/
│
├── Leetcode/                # LeetCode problem solutions organized by problem ID & slug
│   └── DCP-08-26/           # Daily coding problem sets & specialized collections
│
├── *.cpp                    # Codeforces, AtCoder, and custom contest/practice source files
├── *.bin                    # Compiled binaries for local testing & execution
└── .cph/                    # Competitive Programming Helper (CPH) configurations & test cases
```

---

## 🏆 Platforms & OJ Sources

- **[Codeforces](https://codeforces.com/)**: Division rounds, educational rounds, and practice problems (Div. 2, Div. 3, Div. 4).
- **[LeetCode](https://leetcode.com/)**: Daily challenges, weekly/bi-weekly contests, and topic-wise problem solutions.
- **[AtCoder](https://atcoder.jp/)**: Beginner Contests (ABC) and regular contests.
- **[CodeChef](https://www.codechef.com/)**: Starters and monthly challenges.

---

## 🛠️ Tech Stack & Environment

- **Language:** C++ (C++17 / C++20)
- **Editor/IDE:** Visual Studio Code
- **Tooling:** CPH (Competitive Programming Helper) extension for rapid local test case verification.

---

## 💻 Building and Running Locally

To compile and run any C++ solution locally using `g++`:

```bash
# Compile a specific problem file with optimizations
g++ -std=c++20 -O3 ProblemName.cpp -o ProblemName.bin

# Run the compiled binary
./ProblemName.bin
```
